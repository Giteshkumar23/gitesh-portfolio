# Assets Folder

Place your files here before running the project:

## Profile Photo
- File name: `profile.jpg` (or `.png`)
- Place at: `public/assets/profile.jpg`
- Recommended: Square image, min 400×400px, professional headshot
- The Hero section will automatically display it in a circular card.
  If the file is missing, a "G" monogram fallback shows instead.

## Resume
- File name: `Gitesh_Kumar_Patel_Resume.pdf`
- Place at: `public/resume/Gitesh_Kumar_Patel_Resume.pdf`
- This powers the "View Resume" and "Download Resume" buttons.

## Certificate Images (Optional)
- You can add certificate images here and reference them in `src/data/portfolio.js`
- Under `certifications[i].image = "/assets/cert-udemy.jpg"` etc.
